1-2 Corte de Barras (Cut-Rod Bottom-Up & Reconstrução)

Entrada da Q1: p = [0, 1, 3, 11, 16, 19, 10] para comprimentos i = 0..6.

$A[i] = \max_{1 \le j \le i} (p_j + A[i-j])$

Evolução da Tabela Bottom-Up $A[0..6]$ e Cortes Ótimos $S[1..6]$

Comprimento $i$ 0 1 2 3 4 5 6 (Total)
Preço Original $p_i$ 0 1 3 11 16 19 10
Lucro Máximo $A[i]$ 0 1 3 11 16 19 22
1º Corte Ótimo $S[i]$ (Q2) - 1 2 3 4 5 3

Detalhamento para $i = 6$ (Questão 1)

• $j = 1: p_1 + A[5] = 1 + 19 = 20$
• $j = 2: p_2 + A[4] = 3 + 16 = 19$
• $j = 3: p_3 + A[3] = 11 + 11 = \mathbf{22}$ ★ (MÁXIMO)
• $j = 4: p_4 + A[2] = 16 + 3 = 19$
• $j = 5: p_5 + A[1] = 19 + 1 = 20$
• $j = 6: p_6 + A[0] = 10 + 0 = 10$
Resultado: $\max(20, 19, \mathbf{22}, 19, 20, 10) = 22$.

Reconstrução dos Pedaços (Questão 2)

1. Inicia com $n = 6$: primeiro corte $S[6] = 3$.
2. Barra restante: $6 - 3 = 3$.
3. Avalia $n = 3$: próximo corte $S[3] = 3$.
4. Barra restante: $3 - 3 = 0$ (Termina).
Pedaços Finais: Barra cortada em 2 pedaços de tamanho 3 ($3 + 3 = 6$) gerando receita total $11 + 11 = \$22$.
Complexidade de Tempo: $\sum_{i=1}^n i = \Theta(n^2)$ Complexidade de Espaço: $\Theta(n)$ para os vetores $A[0..n]$ e $S[1..n]$ Melhoria monumental em relação à força bruta recursiva $\Omega(2^n)$

Questão 5: Mínimo (Com Repetição)

Para $k = 13$, a combinação ótima é:
5 + 8 = 13 ($2$ moedas).

Complexidade: $O(k \cdot n)$ pseudo-polinomial.

Questão 6: Troco Sem Repetição (0/1)

Cada moeda pode ser usada no máximo uma vez.
Transição 2D: $\min(M[i-1, v], 1 + M[i-1, v - c_i])$.
Se 1D: laço de $v$ decrescente de $k$ até $c_i$.

Questão 7: Contagem de Formas

Combinações distintas (subconjuntos):
Laço externo: moedas $j = 1 \dots n$.
Laço interno: $v = c_j \dots k$.
$dp[v] = dp[v] + dp[v - c_j]$.

Mochila com Repetições (Q9 - Unbounded)

• Diferença de Recorrência 2D:
$K[i, w] = \max(K[i-1, w], \; \mathbf{K[i, w - w_i]} + v_i)$
• Vetor 1D: $K[w] = \max_{1 \le i \le n} (K[w - w_i] + v_i)$ com laço de $w$ crescente de $1 \dots W$.
Complexidade: $O(n \cdot W)$ tempo e apenas $O(W)$ espaço!

10 LCS: Recuperação da Sequência Comum Mais Longa

Modificação de LCS-LENGTH para retornar a sequência de caracteres por backtracking ou matriz de setas $B$.

1. Relação de Recorrência da Matriz

$M[i, j] = \begin{cases} 0, & \text{se } i=0 \text{ ou } j=0 \\ M[i-1, j-1] + 1, & \text{se } x_i = y_j \\ \max(M[i-1, j], M[i, j-1]), & \text{se } x_i \ne y_j \end{cases}$

Quando $x_i = y_j$, a letra obrigatoriamente pertence à LCS e movemos diagonalmente ($\nwarrow$).

2. Pseudocódigo da Reconstrução

PRINT-LCS(B, X, i, j):
  if i == 0 or j == 0:
      return
  if B[i, j] == "DIAGONAL":
      PRINT-LCS(B, X, i - 1, j - 1)
      print(X[i])
  else if B[i, j] == "UP":
      PRINT-LCS(B, X, i - 1, j)
  else:
      PRINT-LCS(B, X, i, j - 1)
Tempo: $\Theta(m \cdot n)$ preenchimento + $O(m + n)$ reconstrução Espaço: $\Theta(m \cdot n)$ Pode economizar a tabela $B$ fazendo backtracking direto em $M$!
