Questão 1

Árvore de Decisão para $n = 4$

Entrada: $A = \langle x_1, x_2, x_3, x_4 \rangle$. Cada nó interno executa uma comparação binária ($x_i \le x_j$).

(a) Número de Folhas l = 4! = 24

Cada permutação possível deve ter ao menos 1 folha alcançável.

(b) Altura da Árvore h = 5

$2^h \ge 24 \implies h \ge \lceil \log_2(24) \rceil = 5$. O algoritmo de Ford-Johnson atinge exatamente $h = 5$.

(c) Cota Inferior Ω(n log n)

A altura $h$ representa o pior caso de comparações. Como $h \ge \log_2(n!) = \Omega(n \log n)$, nenhum algoritmo baseado em comparações é sub-linear.

Questão 3 • Ordenação Estável

Execução Passo a Passo do Counting Sort

$n = 18$ elementos, chaves inteiras no intervalo $[0, 4]$ ($k = 4$).

Fase 4: Alocação Pronto para iniciar
Passo: 0 / 18 Velocidade:
Vetor de Entrada $A[1 \dots 18]$: Lido da direita para esquerda ($j = 18 \dots 1$) para garantir estabilidade
Vetor Auxiliar $C[0 \dots 4]$ (Somas Acumuladas & Ponteiros de Posição): Valores acumulados: [1, 4, 9, 14, 18]
Vetor de Saída Ordenado $B[1 \dots 18]$: 0 de 18 posições preenchidas
💡 O Segredo da Estabilidade no Counting Sort

O laço percorre $A$ de trás para frente ($j = 18$ até $1$). Como $C[v]$ guarda o limite superior da posição de $v$, o último elemento $v$ de $A$ vai para a posição mais à direita do seu bloco em $B$. Os elementos anteriores vão ocupando posições decrescentes. Se percorrêssemos da esquerda para a direita, a ordem relativa seria invertida, quebrando a estabilidade necessária para o Radix Sort!

Questão 5 • Comparação Assintótica

Quando o Radix Sort empata com o Merge Sort?

O Merge Sort opera em tempo $\Theta(n \log n)$. O Radix Sort opera em tempo $\Theta(d(n + k))$. Quando eles possuem a mesma complexidade?

Condição Matemática de Equivalência

Para que $\Theta(d(n + k)) = \Theta(n \log n)$, é necessário que:

  • A base seja constante: $k = \mathcal{O}(1)$ (ex: binário $k=2$ ou decimal $k=10$);
  • O número de dígitos seja logarítmico: $d = \Theta(\log n)$.
Θ(&log n × (n + 2)) = Θ(n &log n)

Cenário Prático Típico

Ordenação de $n$ inteiros com magnitude máxima $N = n^c$ (polinomial em $n$).

Se ordenarmos bit a bit em binário ($k = 2$):

d = ⌈&log₂ N⌉ = ⌈&log₂(n^c)⌉ = c &log₂ n = Θ(&log n)

Bit a bit, o Radix Sort perde a vantagem linear e empata assintoticamente com o Merge Sort!
